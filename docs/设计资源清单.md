# 设计资源清单 · 大学 NPC 任务轴

小程序名：**大学 NPC 任务轴**（`人机共思` 主体下第 2 个小程序）
用途：2026 微信小程序开发大赛参赛作品，提报截止 **2026-10-17**

---

## 一、为什么需要这些图

1. **tabBar 目前完全没有图标**，只有 4 个文字。微信底部导航无图标会显得未完成，也是评审"用户体验感"项的扣分点。
2. **页面内 25 个位置在用 emoji 当图标**。emoji 依赖系统字体：iOS 一套、安卓厂商各一套，我们已在无头 Chromium 里实测出现豆腐块。同一张界面在不同手机上观感不一致，且无法统一色值。
3. 徽章、章节、桌宠是养成系统的核心反馈物，用 emoji 表达没有辨识度，也做不出"想要收集"的感觉。

---

## 二、设计规范（请沿用，勿另起配色）

| 用途 | 色值 |
|---|---|
| 主色 / 选中态 | `#6C4BE8` → `#8E6BFF`（线性渐变 135°） |
| 页面底色 | `#F4F5F8` |
| 卡片 | `#FFFFFF`，圆角 18px（375 基准） |
| 奖励 / 章节高亮 | `#F5B93F`，浅底 `#FFF4DC`，深字 `#8A5B00` |
| 临期警示 | `#F2555A`，浅底 `#FFECEE` |
| 完成 | `#22B573`，浅底 `#E6F7EF` |
| 未选中 / 次要文字 | `#9A98A3` |
| 主文字 | `#1C1B22` |

**风格建议**：2px 描边线性图标，圆头圆角，填充克制（选中态可填主色）。徽章与桌宠可用少量金色渐变点缀。**避免**拟物厚涂和彩色 emoji 感。

后台上传要求方形、≥ 144px，圆形裁切显示。

| 文件名 | 尺寸 | 说明 |
|---|---|---|
| `logo.png` | 1024 × 1024 | 主图，中心构图，留出圆形裁切安全区 |

**内容方向**：地图 + 节点 + 游戏任务感的抽象符号，不要出现文字（"NPC 任务轴"四个字在小尺寸下会糊）。深色底或主色渐变底均可，需在一灰一白两种背景上都清晰。
